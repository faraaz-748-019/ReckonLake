# ReconLake Documentation

**ReconLake** is a locally runnable, reconciliation-first, security-by-design UPI-style transaction lakehouse built entirely with free, open-source tools and 100% synthetic data.

> **Disclaimer**: ReconLake is a portfolio engineering project using synthetic data only. It is not a certified payments or production banking system.
